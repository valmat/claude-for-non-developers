# Feedback on the working set

How the working set (the `task` and `handoff` skills, the rules in `CLAUDE.md`, the installer)
helped or got in the way. The owner may send this file to the set's authors to improve it.

**Write it so that it can be sent as is:** about the process and the set only. No project content,
no business details, no names, no keys, no paths that reveal anything private. English. One
section per session, newest last.

```
## <date> · set <version> · <model> · <surface: terminal | desktop | IDE | unknown> · <kind: install | tiny | task, phase n–m>
### What helped
- what changed a decision or prevented a mistake, not what merely felt right
### What got in the way
- friction, a rule that did not fit, something missing; a suggested fix if you have one
### Context
- how long the session got, whether it was compacted, which context notices arrived
### The owner said
- only if they answered the optional question; quoted, with project details removed
```
